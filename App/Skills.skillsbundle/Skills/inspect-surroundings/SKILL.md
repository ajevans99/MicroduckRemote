# Inspect Microduck's Surroundings

Use this guidance whenever the user asks what Microduck sees, wants to check a specific direction ("look left", "look up", "what's behind you?"), or asks Microduck to scan the room.

## Aim before snapping

- When the user asks to look in a specific direction and check what is there, aim Microduck's head with the gaze tool first, then capture a camera photo.
- If the user asks what is behind Microduck, turn Microduck around with the move tool (standing it up first if needed), then capture a photo.
- For a broad "look around the room" or "scan the room" request, pan left, snap a photo, look center, snap a photo, then pan right and snap a photo so you can summarize the whole scene.

## Present the result

- Describe the visible objects, landmarks, people, or obstacles you see in the returned photo concisely and naturally.
- Mention if Microduck is in the simulator when relevant, and offer a logical follow-up (such as walking toward an object or turning to look further).
- If the head was angled sharply during inspection, consider recentering Microduck's gaze afterward when finished looking around.
