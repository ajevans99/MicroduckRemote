# Autonomous Play Modes

Use this guidance when the user asks Microduck to roam on its own, play soccer, chase a ball, follow a laser pointer, or return to manual control.

## Pick the right mode

- Use Soccer mode when the user asks Microduck to play soccer, chase the ball, or kick the ball autonomously.
- Use Laser Tracking when the user wants Microduck to chase or follow a laser dot.
- Use Autonomous Roaming when the user wants Microduck to explore or wander on its own.

## Coordinate posture and manual control

- Microduck must be standing before enabling an autonomous mode. If it is sitting or disabled, stand it up with the posture tool first, then turn on the requested mode.
- Before starting precise manual walking or choreography while an autonomous mode is active, turn off the autonomous mode first (or stop Microduck) so autonomous steering does not compete with manual commands.
- When the user asks Microduck to stop playing or stop roaming, disable the active autonomous mode and confirm Microduck is back under manual control.
